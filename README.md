# Arc Store

## EN:
Arc Store is app for [ArcOS](https://github.com/zcharka/ArcOS). App can:
- install packages
- uninstall packages
- Clear cache

## Dependencies:
- python-gobject
- gtk4
- libadwaita
- python
- desktop-file-utils
- hicolor-icon-theme

## PL:
